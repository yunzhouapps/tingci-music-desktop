# Tauri 2 + Vue 3 音乐播放器

一个基于 Tauri 2 + Vue 3 构建的极简、无广告音乐播放器。

## 特性

- 极简风格
- 无广告
- 内存占用小

## 开发说明

本项目基于 Vite 中的 Tauri 2 + Vue 3 构建。  
前端使用 Vue 3 `<script setup>` 单文件组件。想了解更多，请查看 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup)。
